# Traffic Optimization System

Dynamic 8-junction traffic simulation frontend built with React, TypeScript and React-Konva.

## Features
- 4 x 2 connected junction grid with eight-way approaches
- Adaptive traffic signals using pressure and waiting-time fairness
- Dynamic congestion visualization
- Cars, bikes, buses, trucks, ambulances, fire trucks and police
- Add vehicles with source/destination selection
- Emergency vehicle priority
- Road inspection, lane/capacity/speed editing and road disabling
- Simulation controls and live network statistics
- Rendering state is separated from the simulation engine for future WebSocket backend integration

## Run
```bash
npm install
npm run dev
```
